# AGENTS.md — правила для AI-агента (Cursor)

## 0. Экономия токенов (обязательно)
- НЕ перечитывай весь чат и весь репозиторий. Начало любой сессии: прочитай только `AGENTS.md` и `docs/STATE.md`.
- Читай только файлы, которые меняешь. Не вызывай `ls -R`, не открывай `data/`, `outputs/`, `*.pt`, `*.csv` целиком (используй `head`, `wc -l`).
- Ответы короткие: что сделано, метрика, следующий шаг. Без пересказа условий и кода, который уже в файлах.
- После каждого значимого шага допиши в `docs/STATE.md` 3-5 строк (что сделано, результат, следующий шаг). Чат — не память, файл — память.
- Результаты экспериментов пиши в `outputs/experiments.csv` (одна строка на запуск), не в чат.
- Логи обучения смотри через `tail -n 20`, а не целиком.
- Не читай .ipynb целиком: ищи нужную ячейку по заголовку. Если вывод ячейки длиннее 30 строк, не выводи его в чат.
- tqdm и per-batch логи отключены; печатай одну строку на эпоху.

## 1. Задача
Классификация спутниковых снимков, 20 классов (список в README.md). Метрика — Accuracy. Цель: максимум на private leaderboard, минимум 65%.
Данные: ~250 train / ~35 val / ~415 test на класс. Test больше train, на нём артефакты (blur, инверсия цвета, низкое разрешение).

## 2. Жёсткие ограничения
- Только предобученные: AlexNet, Inception, VGG, ResNet (`torchvision.models`). Другие архитектуры (EfficientNet, ViT, ConvNeXt и т.д.) ЗАПРЕЩЕНЫ.
- Ансамбль из разрешённых моделей допустим, но сначала уточни у пользователя, что это разрешено правилами.
- Результат должен быть воспроизводимым: фиксированные seed, `requirements.txt`, один скрипт `python -m src.predict`, воспроизводящий submission.
- Код должен быть уникальным. Не копируй чужие решения, ноутбуки Kaggle или код из открытых репозиториев целиком. Пиши свою структуру, свои имена и свою аугментацию.
- Тестовые данные НЕЛЬЗЯ использовать для обучения (в том числе pseudo-labeling без согласования с пользователем). Подбор гиперпараметров — только по val.
- Дедлайн: загрузка на Moodle до 14 октября, 14:00. План — финальный submission за 1 день до дедлайна.

## 3. Железо (обучение локально)
- GPU: RTX 3060 12 GB (Ampere, поддерживает AMP fp16/bf16), RAM 32 GB DDR4-3200, CPU Ryzen 5 3600 (6 ядер / 12 потоков).
- Всегда: `torch.autocast` (AMP), `channels_last`, `torch.backends.cudnn.benchmark=True` (для воспроизводимости зафиксируй seed и запиши в STATE.md, что benchmark включён).
- Стартовые batch_size при 224x224 (подбери по факту, оставляя ~1 GB запаса VRAM):
  - ResNet18/34: 128
  - ResNet50: 64
  - ResNet101: 32-48
  - VGG16/19(-BN): 32 (VGG тяжёлый по памяти)
  - Inception v3 (299x299): 48
  - AlexNet: 128+
- DataLoader: `num_workers=6` (на Windows начни с 4), `persistent_workers=True`, `pin_memory=True`, `prefetch_factor=2`. Если CPU упирается (GPU util < 70%), сначала сделай кэш (ниже), а не добавляй воркеры.
- Датасет маленький: один раз закэшируй изображения, уменьшенные до ~256 px по короткой стороне, в RAM или в `data/cache/*.npy`. Аугментации применяй на лету. Так CPU не будет узким местом.
- При CUDA OOM: уменьши batch в 2 раза, затем включи gradient accumulation, чтобы эффективный batch остался прежним.
- Один запуск обучения <= 30-40 минут. Дольше — только после согласования с пользователем.
- Проверка перед запуском: `torch.cuda.is_available()` должен быть True. Если False, остановись и сообщи пользователю, не обучай на CPU.

## 4. Рекомендуемый план
1. Baseline: ResNet50 (или ResNet34), заморозить backbone, обучить только голову 3-5 эпох. Замерить val accuracy.
2. Fine-tuning: разморозить всё, discriminative LR (backbone 1e-4, голова 1e-3), AdamW, cosine scheduler, label smoothing 0.1.
3. Аугментации (torchvision.transforms v2), имитирующие артефакты теста:
   - RandomResizedCrop, flips (H/V), RandomRotation(90°-кратные)
   - ColorJitter, RandomGrayscale, RandomInvert(p≈0.1-0.2)
   - GaussianBlur, понижение разрешения (Resize вниз и обратно вверх)
   - RandomErasing, опционально MixUp/CutMix
4. Сравнить ResNet50/101, VGG16/19-BN, Inception v3 (вход 299), AlexNet как слабый baseline. Выбрать лучшее по val.
5. TTA на инференсе (flip, rotate90), при необходимости ансамбль 2-3 моделей (см. ограничение выше).
6. Финал: дообучить лучшую конфигурацию на train+val с теми же гиперпараметрами и числом эпох (только после согласования с пользователем), сгенерировать submission.

## 6. Самопроверка (выполняй перед каждым «готово»)
Проходи чек-лист минимум два раза: сразу после написания и после запуска.
- [ ] Код запускается без ошибок на небольшом срезе данных (smoke test: 1 эпоха, 2 batch).
- [ ] Количество классов = 20, метки 0-19 соответствуют README. Порядок классов не перепутан между train/val/predict.
- [ ] Нет утечки: test не использовался в обучении и подборе параметров; val-аугментации без случайности (только resize/normalize).
- [ ] Нормализация ImageNet (mean/std) одинакова в train и inference. Для Inception размер 299.
- [ ] Модель в `model.eval()` и `torch.no_grad()` на инференсе.
- [ ] Seed зафиксирован (python, numpy, torch, cuda), `cudnn.deterministic` задокументирован.
- [ ] Повторный запуск `predict.py` даёт идентичный CSV (сравни хэш двух файлов).
- [ ] Submission: ровно по одной строке на каждый тестовый id, ни одного пропуска/дубля, label — int 0-19, заголовок `id,label`.
- [ ] Формат id (например `12.jpg`) совпадает с именами файлов теста; сверь со `sample_submission`, если он есть.
- [ ] Имя файла: `Name_Surname.csv`. Имя и фамилию спроси у пользователя, не выдумывай.
- [ ] Val accuracy > 65%; если нет — не отправляй, ищи причину.
- [ ] Метрика посчитана на val независимым кодом (sklearn `accuracy_score`) и совпала с метрикой из train-цикла.

## 9. Формат работы (из baseline Week5_baseline.ipynb)
- Основной артефакт — ноутбук, выполняемый end-to-end с SEED=42. Отдельные модули в src/ допустимы, но финальный результат должен воспроизводиться ноутбуком.
- Данные: train/ val/ test/ + train.csv, val.csv (id,label), test.csv (id), classes.csv. id уже с расширением (`1000.jpg`). Путь к данным — переменная окружения CONTEST_DATA.
- Модель = torchvision-backbone с ImageNet-весами + собственный классификатор через nn.Sequential, минимум один размороженный блок. Допустимы: alexnet, vgg*(_bn), googlenet, inception_v3, resnet18-152.
- Внешние данные запрещены.
- Для ImageNet-моделей: IMG_SIZE 224 (inception_v3: 299), Normalize mean=(0.485,0.456,0.406), std=(0.229,0.224,0.225).
- Не менять cudnn.benchmark=False и deterministic=True.
- Перед коммитом очищай вывод ячеек ноутбука (`jupyter nbconvert --clear-output --inplace`), чтобы не раздувать репозиторий.
- Обязательные пункты задания: сравнение с MLP/CNN (таблица + графики), confusion matrix на val с разбором ошибок, объяснение, какое изменение дало максимальный прирост.
- Базовые результаты для сравнения: MLP 0.356, simple CNN 0.549 (val accuracy).
